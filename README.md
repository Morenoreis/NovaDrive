# Dashboard de Concessionárias

Painel somente leitura sobre o banco de dados PostgreSQL de uma rede de concessionárias, construído em Python + Streamlit. Projeto utilizando técnicas de Spec-Driven Development (SDD) com Claude Code.

> **Projeto com fins didáticos**, criado para praticar o Spec-Driven Development (SDD) com Claude Code. Não é um sistema em produção.

## Estrutura

Regras técnicas estão em `CLAUDE.md`, specs em `specs/<pastas>/` (requeriments.md, design.md, tasks.md), diagrama em `docs/`, prompt prontos em `prompts.md`.

## Como Implementar

Abra o Claude Code na raiz desta pasta e use os prompts de `prompts.md`, um por spec, na ordem numérica.
